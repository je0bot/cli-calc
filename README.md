# CLI Calculator 🧮

A command-line calculator built using Python that evaluates mathematical expressions with proper operator precedence.

---

## 🚀 Features

* Supports basic operations: `+`, `-`, `*`, `/`
* Handles operator precedence (e.g., `5 + 3 * 2`)
* Input with or without spaces (`5+3*2` works)
* Maintains calculation history
* Commands:

  * `history` → show past calculations
  * `clear` → clear history
  * `exit` → exit program

---

## 🛠️ Tech Used

* Python
* Regex (`re` module)

---

## ▶️ How to Run

```bash
python cli_calc.py
```

---

## 💡 Example Usage

```text
>>> 5 + 3 * 2
Result: 11

>>> history
1. 5 + 3 * 2 = 11
```
